# ImageContexter

Classify images into category folders using a local VLM (Moondream). 100% free, runs entirely offline.

## Quick Start

```bash
pip install -e .
imagecontexter classify ./photos -c categories.yaml
```

## Features

- Zero cost, fully local inference
- Moondream 0.5B or 2B model
- Copy or move modes
- Dry-run preview
- CSV/JSON reports
